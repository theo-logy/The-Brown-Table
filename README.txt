THE BROWN TABLE — LOGO + PHOTO PLACEHOLDERS

Open index.html in a browser.
The selected latest logo is in assets/the-brown-table-logo.jpg and is used in the header and footer.

TO ADD YOUR OWN PHOTOS:
1. Put your actual brownie photos in the assets folder, named hero-brownies.jpg and protein-brownie.jpg.
2. In index.html, replace each <div class="image-placeholder"> ... </div> with an <img> tag:
   Hero: <img src="assets/hero-brownies.jpg" alt="Our freshly baked protein brownies">
   Product: <img src="assets/protein-brownie.jpg" alt="The Brown Table protein brownie">
3. Keep the rest of the layout unchanged.

Note: The logo is a generated raster image, not an editable SVG.
Configure WhatsApp in script.js before launch.
